## 🔧 框架改进

### 1. Validator 支持 tuple 输出

**改进前**: 只支持单个 tensor 输出
```python
def validate(self, actual: torch.Tensor, expected: torch.Tensor):
    ...
```

**改进后**: 支持 tuple 输出 (量化算子)
```python
def validate(self, actual, expected):
    if isinstance(actual, tuple) and isinstance(expected, tuple):
        # 找到第一个 tensor 元素验证
        ...
```

**优势**:
- ✅ 支持量化算子 (返回 quant + scale)
- ✅ 支持对齐算子 (返回 tensor + int)
- ✅ 向后兼容
