### 2. MoE 融合算子组合策略

```python
# 1. TopK routing
topk_weights, topk_ids = torch.topk(router_logits, top_k, dim=-1)
topk_weights = F.softmax(topk_weights, dim=-1)

# 2. Expert computation (批量操作)
expert_outputs = []
for i in range(num_experts):
    mask = (topk_ids == i)
    x_expert = x[mask.any(dim=-1)]
    expert_outputs.append(torch.mm(x_expert, expert_weights[i]))

# 3. Weighted sum (einsum)
output = torch.einsum('enh,ne->nh', expert_outputs_stacked, topk_weights)
```

**优势**:
- ✅ 纯 PyTorch 实现
- ✅ 易于理解和调试
- ✅ 性能良好

### 3. 量化算子返回多个输出

```python
# 返回 (量化值, scale)
def forward(self, x, group_size=128):
    scales = x_grouped.abs().max(dim=-1, keepdim=True)[0] / 127.0
    x_quant = (x_grouped / (scales + 1e-8)).round().clamp(-127, 127)
    return x_quant.to(torch.int8), scales.squeeze(-1)
```

**优势**:
- ✅ 同时返回量化值和 scale
- ✅ validator 自动处理 tuple
- ✅ 符合量化算子标准接口
