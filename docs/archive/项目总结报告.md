# FlagOpBench 项目总结报告

## 项目概述

在 NVIDIA H20 平台上建立了统一性能基线测试框架，针对 55 个关键算子中的 23 个（42%）完成了 PyTorch 基线实现，并完成了 119 个测试场景的性能验证。

---

## 完成情况

### 1. 核心框架（100% 完成）

| 模块 | 文件 | 功能 | 状态 |
|------|------|------|------|
| 双轨计时器 | `framework/timer.py` | Device event + Wall clock | ✅ |
| 精度校验 | `framework/validator.py` | 对比 CPU fp32 golden | ✅ |
| Roofline 分析 | `framework/roofline.py` | 自动计算算力/带宽效率 | ✅ |
| 结果输出 | `framework/reporter.py` | JSON 格式结果归档 | ✅ |
| 环境采集 | `framework/env_collector.py` | 硬件/软件版本信息 | ✅ |
| 测试引擎 | `framework/runner.py` | 统一测试执行流程 | ✅ |
| 后端抽象 | `backends/base.py` | 平台无关抽象层 | ✅ |
| NVIDIA 后端 | `backends/nvidia.py` | CUDA 平台适配 | ✅ |
| 算子注册表 | `operators/registry.py` | 统一算子管理 | ✅ |

### 2. 已实现算子（23/55 = 42%）

#### 基础算子（8 个）
- `mm`, `bmm` - 矩阵乘法
- `layernorm`, `rms_norm`, `gemma_rms_norm` - 归一化
- `gelu`, `softmax`, `swiglu` - 激活函数

#### 新增算子（15 个）
- **MoE 相关（6 个）**: `moe_sum`, `topk_softplus_sqrt`, `top_k_per_row_prefill`, `top_k_per_row_decode`, `persistent_topk`, `topk_selector`
- **Norm 融合（2 个）**: `add_rmsnorm_bias`, `fused_q_kv_rmsnorm`
- **位置编码（1 个）**: `rope`
- **卷积（2 个）**: `causal_conv1d_prefill`, `causal_conv1d_decode`
- **路由/量化（2 个）**: `router_gemm_bf16_fp32`, `grouped_matmul`
- **通用计算（1 个）**: `fp8_einsum`
- **激活（1 个）**: `silu_and_mul`

### 3. 测试用例（24 个 YAML 文件，119 个场景）

每个算子配置了 4-7 个真实模型场景：
- DeepSeek-V3 (MoE 160 experts, hidden 7168)
- LLaMA (32 heads, hidden 4096)
- Gemma (2B/7B/27B)
- Mamba (d_model 2560, kernel_size 4)

## 性能测试结果（NVIDIA H20）

### Compute-bound 算子（高效）
| 算子 | 场景 | 平均耗时 | 计算效率 | 瓶颈 |
|------|------|---------|---------|------|
| mm | deepseek_v3_ffn_up | 4.25 ms | **86.0%** | compute |
| bmm | batch64_seq2048 | 0.82 ms | **85.5%** | compute |
| fp8_einsum | bmm_128heads_seq2048 | 1.08 ms | **85.6%** | compute |
| grouped_matmul | deepseek_v3_prefill | 5.77 ms | **63.4%** | compute |

### Memory-bound 算子（符合预期）
| 算子 | 场景 | 平均耗时 | 带宽效率 | 瓶颈 |
|------|------|---------|---------|------|
| layernorm | hidden_7168_seq2048 | 0.05 ms | 27.4% | memory |
| rms_norm | hidden_7168_seq2048 | 0.33 ms | 4.5% | memory |
| rope | deepseek_v3_rope_prefill | 0.73 ms | 13.8% | memory |
| moe_sum | deepseek_v3_prefill | 0.67 ms | 9.8% | memory |

### TopK 类算子（算法复杂度高）
| 算子 | 场景 | 平均耗时 | 带宽效率 |
|------|------|---------|---------|
| top_k_per_row_prefill | deepseek_v3_2048 | 0.05 ms | 0.4% |
| persistent_topk | large_k_64 | 0.18 ms | 2.4% |
| topk_softplus_sqrt | deepseek_v3_router | 0.06 ms | 0.3% |

## 使用指南

### 1. 查看已注册算子
```bash
python baseline/run.py list
```

### 2. 运行单个算子测试
```bash
python baseline/run.py run \
  --backend nvidia \
  --case baseline/cases/basic/mm.yaml \
  --platform nvidia_h20
```

### 3. 运行全部基础算子
```bash
python baseline/run.py run \
  --backend nvidia \
  --case-dir baseline/cases/basic/ \
  --platform nvidia_h20
```

### 4. 跨平台对比
```bash
python baseline/run.py compare \
  --results results/nvidia_h20.json \
            results/ascend_910b.json
```

### 5. 版本回归检测
```bash
python baseline/run.py regression \
  --baseline results/torch2.4.0.json \
  --current results/torch2.5.0.json \
  --threshold 5
```
