## 💡 技术亮点

### 1. 三层优先级架构
```python
if HAS_VLLM_OPS:
    vllm_ops.rms_norm(...)  # 最快
elif hasattr(F, 'rms_norm'):
    F.rms_norm(...)         # 次快
else:
    manual_impl(...)        # 兜底
```

### 2. 批量操作替代循环
- grouped_matmul: 从循环改为 `torch.bmm`
- 预期性能提升: 3-5x

### 3. 使用 einsum 简化代码
- moe_sum: 从 broadcast 改为 `torch.einsum`
- 代码更简洁，性能更好

### 4. Roofline 性能分析
- 自动计算效率指标
- 判断瓶颈类型
