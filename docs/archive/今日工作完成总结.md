## 🏗️ 技术架构亮点

### 1. 三层优先级架构（算子实现）

```
vLLM CUDA → PyTorch 官方 → 手动 fallback
```

自动选择最优实现，确保始终可用

### 2. 三层抽象架构（多平台支持）

```
应用层 (run.py)
    ↓ 平台无关
抽象层 (BenchmarkTimer/Backend)
    ↓ 统一接口
平台层 (CudaTimer/AscendTimer/MuxinTimer)
```

应用代码完全平台无关

### 3. 批量操作替代循环

`grouped_matmul`: 循环 → `torch.bmm` (预期 3-5x 提升)

### 4. 使用 einsum 简化代码

`moe_sum`: broadcast → `torch.einsum` (更快更清晰)

### 5. 双轨计时系统

- Device Event (主) - 纯 GPU 执行时间
- Wall Clock (辅) - 含 CPU 调度开销

精确测量 + 开销分析
