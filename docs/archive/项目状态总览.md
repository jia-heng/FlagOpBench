## 🚀 核心工具

### 1. flashinfer-trace 导入器

**文件**: `scripts/import_flashinfer_trace.py` (12KB)

**功能**: 从 HuggingFace flashinfer-trace 导入真实推理 shape

**使用**:
```bash
git clone https://huggingface.co/datasets/flashinfer/flashinfer-trace
python scripts/import_flashinfer_trace.py \
  --dataset-path flashinfer-trace \
  --output-dir baseline/cases
```

**覆盖**: 190+ Definition，1500+ Workload（Llama/DeepSeek/Qwen）

### 2. 智能去重过滤器

**文件**: `framework/filters.py` (9.4KB)

**功能**: 语义特征去重，避免 case 爆炸

**特性**:
- `UniqueAxesFilter`: 基础算子按 shape 去重
- `SemanticFilter`: Attention/MoE 按语义去重
- `create_filter()`: 自动工厂函数

**示例**:
```python
from framework.filters import create_filter

filter = create_filter('paged_attention_decode')
filtered = filter.filter(workloads)
# Attention 按 avg_kv_len 去重，而非 batch_size
```

### 3. 自动 Shape 采集器

**文件**: `scripts/collect_shapes.py` (12KB)

**功能**: Hook PyTorch 算子，自动记录真实推理 shape

**使用**:
```bash
python scripts/collect_shapes.py \
  --framework transformers \
  --model meta-llama/Llama-3.1-8B \
  --output-dir collected_shapes
```

### 4. JSON→YAML 转换器

**文件**: `scripts/convert_collected_to_yaml.py` (3.1KB)

**功能**: 转换采集的 JSON 为 FlagOpBench YAML

**使用**:
```bash
python scripts/convert_collected_to_yaml.py \
  --input collected_shapes \
  --output baseline/cases/basic
```
