**关键特性**:

### ✅ 2. 智能去重过滤器

**文件**: `framework/filters.py`

**功能**:
- `UniqueAxesFilter`: 基础算子按 shape 去重
- `SemanticFilter`: 复杂算子按语义特征去重
- 预定义语义函数：`attention_semantic_key`, `moe_semantic_key`, `sampling_semantic_key`
- 自动工厂函数：`create_filter(operator)`

**关键特性**:
- ✅ Attention 按 avg_kv_len 去重（而非 batch_size）
- ✅ MoE 按 avg_tokens_per_expert 去重
- ✅ 避免 case 爆炸，保留代表性样本
- ✅ 统计信息输出

### ✅ 3. 自动 Shape 采集器

- ✅ 自动提取 shape 信息（M, N, K, dtype）
- ✅ 实时去重，避免重复记录
- ✅ 输出统计摘要

## 💡 智能去重示例

### 基础算子（GEMM）

```python
# 按原始 shape 去重
workloads = [
    {"M": 256, "N": 4096, "K": 4096, "dtype": "fp16"},
    {"M": 256, "N": 4096, "K": 4096, "dtype": "bf16"},  # 重复 → 去掉
    {"M": 248, "N": 4096, "K": 4096, "dtype": "fp16"},  # 不同 → 保留
]

filter = create_filter('mm', keep_first_k=1)
filtered = filter.filter(workloads)
# 结果: 2 个（256 和 248）
```

### Attention 算子（语义去重）

```python
# 按 avg_kv_len 去重
workloads = [
    {"batch_size": 8, "num_kv_indices": 584, ...},   # avg_kv_len=73
    {"batch_size": 16, "num_kv_indices": 1168, ...}, # avg_kv_len=73 → 去掉
    {"batch_size": 8, "num_kv_indices": 4096, ...},  # avg_kv_len=512 → 保留
]

filter = create_filter('paged_attention_decode', keep_first_k=1)
filtered = filter.filter(workloads)
# 结果: 2 个（avg_kv_len=73 和 512）
```

**关键发现**: Attention 性能主要受 avg_kv_len 影响，而非 batch_size 绝对值！

## ✨ 质量保证

### 1. Shape 有出处

```yaml
- name: "llama3.1_attn_o_proj_m256"
  M: 256
  N: 4096
  K: 4096
  dtype: fp16
  source: "Llama-3.1-8B, attention output projection"
```

### 2. 智能去重

- 基础算子：按 shape 组合去重
- Attention：按平均序列长度去重
- MoE：按平均每 expert 的 token 数去重

### 3. 覆盖典型工况

- Prefill: 长序列（512, 1024, 2048, 4096）
- Decode: 短序列（1, 8, 16, 32, 64）
- Batch size: power-of-2（1, 2, 4, 8, 16, 32）

### 4. 性能数据可信

官方 SDK + 真实 shape → 性能数据具有行业参考价值 ⭐
