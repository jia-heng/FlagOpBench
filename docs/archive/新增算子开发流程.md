## 📋 详细步骤

### Step 1: 检查实现可用性 ✅

**目标**: 确认 PyTorch 官方或 vLLM 是否有可用实现

#### 1.1 检查 PyTorch 官方实现

```python
# 检查方法
import torch
import torch.nn.functional as F

# 方法 1: 检查 F 模块
if hasattr(F, 'operator_name'):
    print("✅ PyTorch 官方有实现")
    print(f"API: F.{operator_name}")
    
# 方法 2: 检查 torch 模块
if hasattr(torch, 'operator_name'):
    print("✅ PyTorch 官方有实现")
    print(f"API: torch.{operator_name}")
    
# 方法 3: 查看文档
# https://pytorch.org/docs/stable/torch.html
# https://pytorch.org/docs/stable/nn.functional.html
```

**常见 PyTorch 官方算子**:
- `F.scaled_dot_product_attention` - FlashAttention (PyTorch 2.0+)
- `F.rms_norm` - RMSNorm (PyTorch 2.4+)
- `F.layer_norm` - LayerNorm
- `F.gelu`, `F.silu`, `F.softmax` - 激活函数
- `torch.mm`, `torch.bmm` - 矩阵乘法
- `torch.topk` - TopK
- `torch.einsum` - Einstein Summation
- `F.conv1d`, `F.conv2d` - 卷积

#### 1.2 检查 vLLM CUDA 实现

```python
# 检查 vLLM ops
try:
    import torch.ops._C as vllm_ops
    
    # 检查特定算子
    if hasattr(vllm_ops, 'operator_name'):
        print("✅ vLLM 有实现")
        print(f"API: vllm_ops.{operator_name}")
        
except ImportError:
    print("⚠️ vLLM 未安装")
```

**常见 vLLM 算子** (参考 `vLLM_CUDA算子清单.md`):
- `vllm_ops.rms_norm` - RMSNorm
- `vllm_ops.rotary_embedding` - RoPE
- `vllm_ops.paged_attention_v1/v2` - PagedAttention
- `vllm_ops.fused_add_rms_norm` - Fused Add+RMSNorm
- `vllm_ops.silu_and_mul` - SiLU+Mul
- `vllm_ops.moe_align_block_size` - MoE 对齐

#### 1.3 决策规则

```
如果 PyTorch 有官方实现:
    → 优先使用 PyTorch 官方 (Layer 1)
    → 继续 Step 2
    
如果 vLLM 有实现:
    → 作为次选 (Layer 2)
    → 继续 Step 2
    
如果都没有:
    → 🚫 跳过此算子，标记为待实现
    → 记录到 "待实现算子列表"
    → 后续研究手动实现方案
```

**示例决策**:
- ✅ `flashattention` → 使用 `F.scaled_dot_product_attention` (PyTorch 2.0+)
- ✅ `rms_norm` → 使用 `F.rms_norm` (PyTorch 2.4+)
- ✅ `topk` → 使用 `torch.topk`
- 🚫 `flash_mla` → 暂无官方实现，跳过，标记为 P1

### Step 2: 实现算子代码 📝

**目标**: 按照三层优先级实现算子，测试后以性能最优的实现作为基线

**⚠️ 重要原则**: 如果有多种实现方式（PyTorch 官方、vLLM CUDA、手动实现），需要进行性能测试对比，最终**以性能最优的实现作为基线**。优先级（PyTorch > vLLM > 手动）是实现顺序建议，不是最终选择的硬性规则。

#### 2.1 创建算子文件

**文件位置规则**:
```
baseline/operators/
├── attention/      # 注意力算子 (flashattention, sparse_attention, ...)
├── moe/           # MoE 算子 (fused_moe, moe_align_block_size, ...)
├── quantization/  # 量化算子 (gemm_w8a8, per_token_group_fp8_quant, ...)
├── activation/    # 激活函数 (silu_and_mul_with_clamp, ...)
├── norm/          # 归一化 (新增专用目录)
└── basic/         # 基础算子 (兜底目录)
```

**命名规则**:
- 文件名: `operator_name.py` (小写 + 下划线)
- 类名: `OperatorNameOperator` (驼峰命名)
- 注册名: `"operator_name"` (与文件名一致)

## ⚠️ 注意事项

### 必须遵守
1. ✅ **优先级顺序**: PyTorch > vLLM > Manual，不可颠倒
2. ✅ **无实现就跳过**: 如果 PyTorch 和 vLLM 都没有，标记待实现，不要强行手动实现
3. ✅ **真实 shape 优先**: 有 flashinfer-trace 数据就用，没有用大中小，标记 TODO
4. ✅ **测试必须通过**: 100% 测试通过才能合并
5. ✅ **文档必须完整**: 代码注释、YAML source、数据来源都要标注

### 最佳实践
1. 🎯 先实现 P0 算子 (有 PyTorch 官方实现)
