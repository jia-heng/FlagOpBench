## 🔧 代码示例

### RMSNorm 三层优先级

```python
def forward(self, x, weight, eps=1e-6):
    """RMSNorm 前向
    
    优先级:
    1. PyTorch 官方 F.rms_norm (最推荐)
    2. vLLM CUDA kernel (次选)
    3. 手动实现 (fallback)
    """
    if hasattr(F, 'rms_norm'):
        # 优先: PyTorch 官方
        return F.rms_norm(x, [x.shape[-1]], weight, eps)
    elif HAS_VLLM_OPS:
        # 次选: vLLM CUDA kernel
        out = torch.empty_like(x)
        vllm_ops.rms_norm(out, x, weight, eps)
        return out
    else:
        # Fallback: 手动实现
        variance = x.float().pow(2).mean(-1, keepdim=True)
        x_norm = x * torch.rsqrt(variance + eps)
        return (x_norm * weight).to(x.dtype)
```

### TopK 简化实现

```python
def forward(self, x, k=8):
    """TopK - 直接使用 PyTorch 官方实现"""
    values, indices = torch.topk(x, k, dim=-1)
    return values
```
