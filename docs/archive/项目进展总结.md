## 🔧 关键技术方案

### vLLM CUDA Kernel 接入策略

**核心需求**：使用**官方 SDK 实现**而非手动 PyTorch 实现，才具备性能参考价值。

**实现模式**（已应用于 4 个算子）：

```python
# 导入检查
try:
    import torch.ops._C as vllm_ops
    HAS_VLLM_OPS = hasattr(vllm_ops, 'rms_norm')
except (ImportError, AttributeError):
    HAS_VLLM_OPS = False
    print("Warning: vLLM CUDA ops not available, using PyTorch fallback")

# 算子实现
def forward(self, x, weight, eps=1e-6, **kwargs):
    if HAS_VLLM_OPS:
        # 优先使用 vLLM 官方 CUDA kernel
        out = torch.empty_like(x)
        vllm_ops.rms_norm(out, x, weight, eps)
        return out
    else:
        # Fallback: 纯 PyTorch 实现
        variance = x.pow(2).mean(-1, keepdim=True)
        x = x * torch.rsqrt(variance + eps)
        return x * weight
```

## 🔍 技术亮点

1. **官方库优先原则**：坚持使用 vLLM/Flash-Attention 等官方 CUDA kernel，确保性能数据参考价值
2. **优雅降级机制**：所有算子支持 PyTorch fallback，确保功能可用性
3. **Roofline 分析**：自动分析算子是 compute-bound 还是 memory-bound
4. **多后端抽象**：统一接口支持 NVIDIA/Ascend/Muxin 三大平台
5. **双计时系统**：device event time（主指标）+ wall clock time（含调度开销）
