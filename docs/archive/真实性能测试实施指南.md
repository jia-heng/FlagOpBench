# 真实性能测试用例设计与实施指南

## 🎯 核心差异点

**FlagOpBench vs 其他 Benchmark 项目**：

| 特性 | 其他项目 | FlagOpBench |
|------|---------|------------|
| Shape 来源 | 人工拍脑袋（M=1024, N=2048...） | 真实推理 trace 采集 ✅ |
| 覆盖度 | 少量典型 case（10-20 个） | 每个算子 30-50 个真实 workload ✅ |
| 去重策略 | 无或简单去重 | 智能去重（语义特征） ✅ |
| 可复现性 | 低（shape 无出处） | 高（标注来源模型） ✅ |

## 📦 已实现的工具

### 1. flashinfer-trace 导入器

**文件**: `scripts/import_flashinfer_trace.py`

**功能**:
- 从 HuggingFace flashinfer-trace 数据集导入真实 shape
- 支持 190+ Definition，1500+ Workload
- 自动转换为 FlagOpBench YAML 格式

**使用方法**:
```bash
# Step 1: 下载 flashinfer-trace 数据集
git clone https://huggingface.co/datasets/flashinfer/flashinfer-trace

# Step 2: 导入所有算子
python scripts/import_flashinfer_trace.py \
  --dataset-path flashinfer-trace \
  --output-dir baseline/cases

# Step 3: 只导入特定算子
python scripts/import_flashinfer_trace.py \
  --dataset-path flashinfer-trace \
  --output-dir baseline/cases \
  --operator gemm attention
```

**输出**:
```
baseline/cases/
├── basic/
│   ├── mm_flashinfer.yaml          # 40-50 个真实 GEMM workload
│   ├── rms_norm_flashinfer.yaml    # 30-40 个真实 RMSNorm workload
│   └── ...
└── model/
    ├── paged_attention_decode_flashinfer.yaml   # 50+ 个 Attention workload
    └── ...
```

### 2. 智能去重过滤器

**文件**: `framework/filters.py`

**功能**:
- `UniqueAxesFilter`: 基础算子按 shape 去重
- `SemanticFilter`: 复杂算子按语义特征去重
- 预定义的语义函数（Attention、MoE、Sampling）

**使用示例**:
```python
from framework.filters import create_filter

# 自动为算子创建合适的过滤器
filter = create_filter('mm', keep_first_k=1)
filtered_workloads = filter.filter(workloads)

# 或手动创建
from framework.filters import SemanticFilter, attention_semantic_key
filter = SemanticFilter(semantic_fn=attention_semantic_key)
```

**Attention 语义去重示例**:
```python
# 这两个 workload 性能相近，会被去重保留 1 个
# - batch=8, num_kv_indices=584  → avg_kv_len=73
# - batch=16, num_kv_indices=1168 → avg_kv_len=73

# 这两个性能差异大，都会保留
# - batch=8, avg_kv_len=73
# - batch=8, avg_kv_len=512
```

### 3. 自动 Shape 采集器

**文件**: `scripts/collect_shapes.py`

**功能**:
- Hook PyTorch 算子调用，自动记录 shape
- 支持 transformers、sglang 框架
- 自动去重，输出 JSON

**使用方法**:
```bash
# 从 transformers 模型采集
python scripts/collect_shapes.py \
  --framework transformers \
  --model meta-llama/Llama-3.1-8B \
  --output-dir collected_shapes

# 从 sglang 采集
python scripts/collect_shapes.py \
  --framework sglang \
  --model deepseek-ai/DeepSeek-V3 \
  --output-dir collected_shapes

# 从自定义脚本采集
python scripts/collect_shapes.py \
  --framework custom \
  --custom-script my_inference.py
```

**输出**:
```json
{
  "operator": "mm",
  "num_unique_shapes": 43,
  "shapes": [
    {"M": 2048, "K": 7168, "N": 18432, "dtype": "bfloat16"},
    {"M": 4096, "K": 7168, "N": 18432, "dtype": "bfloat16"},
    ...
  ]
}
```

## 🚀 实施路线

### Phase 1: 集成 flashinfer-trace（推荐优先）

**预期时间**: 1-2 小时

**步骤**:
1. 下载 flashinfer-trace 数据集
   ```bash
   git clone https://huggingface.co/datasets/flashinfer/flashinfer-trace
   ```

2. 导入 GEMM、RMSNorm 等基础算子
   ```bash
   python scripts/import_flashinfer_trace.py \
     --dataset-path flashinfer-trace \
     --output-dir baseline/cases \
     --operator gemm rms_norm
   ```

3. 验证生成的 YAML
   ```bash
   ls -lh baseline/cases/basic/*_flashinfer.yaml
   cat baseline/cases/basic/mm_flashinfer.yaml | head -30
   ```

4. 运行测试
   ```bash
   python baseline/run.py run --backend nvidia \
     --case baseline/cases/basic/mm_flashinfer.yaml \
     --platform nvidia_h20
   ```

**预期成果**:
- GEMM: 40-50 个真实 workload（来自 Llama/DeepSeek/Qwen）
- RMSNorm: 30-40 个真实 workload
- 每个 workload 标注来源模型

### Phase 2: 补充基础算子自采集

**预期时间**: 2-3 小时

**步骤**:
1. 运行 shape 采集器
   ```bash
   python scripts/collect_shapes.py \
     --framework transformers \
     --model meta-llama/Llama-3.1-8B \
     --output-dir collected_shapes \
     --operators mm bmm layer_norm softmax
   ```

2. 转换 JSON → YAML
   ```bash
   python scripts/convert_collected_to_yaml.py \
     --input collected_shapes \
     --output baseline/cases/basic
   ```

3. 应用智能去重
   ```python

   # 读取 collected shapes
   with open('collected_shapes/mm_shapes.json') as f:
       data = json.load(f)
   
   # 去重
   filter = create_filter('mm', keep_first_k=1)
   filtered = filter.filter(data['shapes'])
   
   # 保存为 YAML
   ...
   ```

**预期成果**:
- 补充 flashinfer-trace 未覆盖的算子
- 每个算子 30-50 个 workload

## 🎯 质量保证

### 1. Shape 有出处

每个 workload 标注来源：
```yaml
- name: "llama3.1_attn_o_proj_m256"
  M: 256
  N: 4096
  K: 4096
  dtype: fp16
  source: "Llama-3.1-8B, attention output projection, prefill phase"
```

### 2. 智能去重

避免 case 爆炸，同时保留代表性样本：
- 基础算子：按 shape 组合去重
- Attention：按平均序列长度去重
- MoE：按平均每 expert 的 token 数去重

### 3. 覆盖典型工况

不追求穷举，基于真实推理高频 shape：
- Prefill: 长序列（512, 1024, 2048, 4096）
- Decode: 短序列（1, 8, 16, 32, 64）
- Batch size: power-of-2（1, 2, 4, 8, 16, 32）

### 4. 性能数据可信

使用官方 SDK + 真实 shape → 性能数据具有行业参考价值
